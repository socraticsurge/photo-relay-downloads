# Security policy

Do not post credentials, private videos, OAuth tokens, or an exploitable
security report in a public issue.

Use GitHub's **Report a vulnerability** action on this repository's Security
page. If the application may have exposed Google authorization, revoke Photo
Relay from [Google Account permissions](https://myaccount.google.com/permissions)
while the report is reviewed.

Include the Photo Relay version, macOS version, affected workflow, and minimal
reproduction details. Remove filenames, channel identifiers, local filesystem
paths, and other personal context unless they are essential to reproduce the
problem.
